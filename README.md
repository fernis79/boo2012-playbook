# Playbook Boo FF P12:3

Lagets playbook för säsongen 2026/2027 – publiceras på https://boo2012.se via GitHub Pages.

- `index.html` – appen. Allt innehåll är krypterat (AES-256-GCM) och låses upp med lagets lösenord i webbläsaren.
- `files/` – krypterade nedladdningar (PDF/PPT).
- Ingen klartext, inga spelarbilder och inga lösenord finns i repot.

Filerna byggs och uppdateras automatiskt – ändra dem inte för hand.
